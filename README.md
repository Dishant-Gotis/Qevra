# Qevra

> **A fast, offline, open-source file converter you use by dragging.**  
> Hold a modifier key (`Ctrl` on Windows/Linux, `Option` on macOS), drag files, and drop them on a format slice in the radial menu that opens right at your cursor.
>
> Source code: [https://github.com/Dishant-Gotis/Qevra](https://github.com/Dishant-Gotis/Qevra)

---

## Highlights

- **Right at your cursor**: No app window to hunt down. Radial donut toolbar pops up under your pointer with formats matching the files you drag.
- **Over 270 formats supported**: Images, PDFs, Word, Excel, PowerPoint, HWP/HWPX, 3D models, CAD drawings, archives, ebooks, audio, and video without requiring Microsoft Office or third-party suites.
- **100% Local & Offline**: All processing stays on your device. Nothing is uploaded to any cloud server.
- **Integrated Tools**: Interactive tools for image/PDF cropping, annotation canvas, audio/video trimming, and Excel print layout.
- **Shell & CLI Integrations**: Windows 11 context menu ("Convert with Qevra"), macOS Services, Linux shortcuts, folder watcher automation, and the `qevra` command-line utility.

---

## Installation & Usage

### Windows 10/11
- Run `Qevra-<version>-win-Setup.exe` or extract the portable archive and run `Qevra.exe`.
- Setup registers the Explorer context menu, system startup, and the `qevra` CLI command.

### macOS & Linux
- **macOS**: Drag `Qevra.app` to Applications.
- **Linux**: Run `./install.sh` for user-level installation into `~/.local/share/qevra/`.
